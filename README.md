### 3. Greedy Algorithms (`Greedy - Non Graphs/` & `Greedy - Graphs/`)

#### Non-Graph Greedy Problems
- **Activity Selection Problem** (`Greedy - Non Graphs/activity selection problem/greedy.cpp`): Selecting the maximum number of mutually compatible activities sorted by finish times.
- **Fractional Knapsack Problem** (`Greedy - Non Graphs/fractional knapsack problem/greedy.cpp`): Maximizing total value by taking fractions of items sorted by value-to-weight ratio.

#### Graph Greedy Algorithms
- **Dijkstra's Algorithm** (`Greedy - Graphs/dijkstra/dijkstra.cpp`): Single-source shortest paths on weighted directed/undirected graphs with non-negative edge weights.
- **Bellman-Ford Algorithm** (`Greedy - Graphs/bellman ford/bellmanford.cpp`): Shortest path algorithm supporting negative edge weights and detecting negative weight cycles.
- **Prim's Algorithm** (`Greedy - Graphs/prims/prims.cpp`): Minimum Spanning Tree (MST) growth via vertex-based greedy selection.
- **Kruskal's Algorithm** (`Greedy - Graphs/kruskal/kruskals.cpp`): Minimum Spanning Tree (MST) construction using edge sorting and Disjoint Set Union (DSU / Union-Find).

## 🛠️ How to Compile and Run

All code is written in standard modern C++ (C++17 / C++20 compatible). You can compile any `.cpp` file using `g++` or `clang++`:

```bash
# Example 1: Compile and run Quick Sort
g++ -std=c++17 "Divide and Conquer/quick_sort_implementation/quick_sort.cpp" -o quick_sort.out
./quick_sort.out

# Example 2: Compile and run Dijkstra's Algorithm
g++ -std=c++17 "Greedy - Graphs/dijkstra/dijkstra.cpp" -o dijkstra.out
./dijkstra.out

# Example 3: Compile and run 0/1 Knapsack (Memoization)
g++ -std=c++17 "Dynamic Programming/knapsack/using_memoization.cpp" -o knapsack.out
./knapsack.out
```

> **Note**: A `.gitignore` file is configured in the repository root to automatically ignore all compiled binaries (`*.out`, `*.exe`, `*.o`, etc.) to keep git history clean.
